# GoldEx Companion (همراه گلدکس) 🪙

دستیار جامع، هوشمند و مینیمال ویژه طلافروشان، معامله‌گران و سرمایه‌گذاران بازار طلا، سکه و جواهر بر پایه Jetpack Compose با تم لوکس تیره و پشتیبانی کامل فارسی (RTL).

## 🚀 قابلیت‌های کلیدی نسخه جدید (v0.3.0)
- **کلید امضای پایدار (Seamless App Update):** تعبیه Keystore رسمی و اختصاصی درون پروژه، که امکان آپدیت مستقیم و بدون نیاز به حذف (Uninstall) نسخه‌های پیشین را فراهم می‌سازد.
- **اتصال مستقیم به وب‌سرویس‌های زنده واقعی:**
  - وب‌سرویس **آی‌سیگنال (isignal.ir)** با متد POST و دریافت مظنه لحظه‌ای طلا ۱۸، مثقال، سکه‌ها و ارز
  - وب‌سرویس **طلا.آی‌آر (tala.ir)** به عنوان ارائه‌دهنده مکمل و پشتیبان
  - کلید تعویض ۱-کلیکه منبع استعلام بین آی‌سیگنال و طلا.آی‌آر با نمایش نشانگر زنده
- **طراحی بازطراحی‌شده فوق‌مینیمال و چشم‌نواز:**
  - پالت رنگی لوکس آبسیدین مات (`#0A0B0E`) با جزئیات طلایی شامپاینی (`#DFB35A`)
  - نوار تب کپسولی سگمنتد (`MinimalSegmentedTabBar`) با هایلایت نرم و شناور
  - کارت‌های شیشه‌ای بدون حاشیه‌های سنگین، با خطوط مینیاتوری (`0.6dp`)
  - فرمت‌کننده زنده ارقام همزمان با تایپ کاربر (`VisualTransformation`) بدون پرش مکان‌نما
  - حروف‌نگار مبالغ به زبان فارسی زیر کادرهای ورودی قیمت
- **چهار ماژول تخصصی معاملات طلا:**
  - **طلا و جواهرات:** محاسبه کسر نگین، اجرت (درصدی یا تومانی)، سود ۷٪، مالیات ۹٪ قانونی، و صدور فاکتور با قابلیت کپی و اشتراک‌گذاری
  - **مظنه آبشده و مثقال:** تبدیل ۱۷ به ۱۸ عیار بر اساس فرمول استاندارد طلافروشان و ارزیابی کل قطعه
  - **حباب‌سنج تخصصی سکه:** محاسبه ارزش ذاتی با فرمول رسمی بانک مرکزی، انس جهانی و نرخ دلار و رادار ریسک حباب
  - **تبدیل عیار و وزن:** تبدیل آنی وزن بین عیارهای ۱۸، ۲۱ و ۲۴ عیار

## 🛠 مشخصات فنی
- **Target SDK:** 34 | **Min SDK:** 24 | **Java Version:** 17
- **UI Framework:** Jetpack Compose (Material 3 Minimalist)
- **Architecture:** MVVM + StateFlow + Kotlin Coroutines
- **Signer:** Persistent 2048-bit RSA Keystore (Validity: 10,000 days)
- **CI/CD:** GitHub Actions Automation Loop
