# GoldEx Companion (همراه گلدکس) 🪙

دستیار جامع، هوشمند و فوق‌حرفه‌ای ویژه طلافروشان، معامله‌گران و سرمایه‌گذاران طلا، سکه و جواهر بر پایه Jetpack Compose و طراحی مدرن متریال ۳ به زبان فارسی (RTL).

## 🚀 قابلیت‌های کلیدی و پیشرفته
- **مظنه زنده بازار (GoldEx Live):** بارگذاری خودکار قیمت‌های لحظه‌ای بازار طلا، مظنه آبشده، سکه امامی، بهار، نیم، ربع، سکه گرمی، دلار آزاد و انس جهانی.
- **فرمت‌کننده زنده هنگام تایپ (VisualTransformation):** جداسازی سه‌رقمی ارقام همزمان با تایپ کاربر با حفظ مکان‌نما (Cursor) و پشتیبانی یکپارچه از اعداد فارسی و انگلیسی.
- **حروف‌نگار مبالغ (Persian Words):** تبدیل هوشمند قیمت‌ها به حروف فارسی زیر هر ورودی (مثلاً: *چهار میلیون و پانصد هزار تومان*) جهت جلوگیری از خطای صفر.
- **محاسبه‌گر پیشرفته طلا و زیورآلات:**
  - کسر وزن نگین و سنگ
  - اعمال اجرت ساخت (درصدی یا تومانی)
  - محاسبه سود قانونی طلافروش (۷٪)
  - محاسبه قانونی مالیات ارزش افزوده (۹٪) طبق قانون جدید (صرفاً بر روی سود و اجرت)
  - صدور، کپی و اشتراک‌گذاری فاکتور رسمی
- **محاسبه‌گر مظنه آبشده و مثقال:**
  - تبدیل استاندارد مثقال طلای ۱۷ عیار (مظنه آبشده) به قیمت هر گرم طلای ۱۸ عیار و محاسبه ارزش وزنی
- **حباب‌سنج تخصصی انواع سکه بانکی:**
  - محاسبه دقیق ارزش ذاتی سکه بر اساس فرمول رسمی بانک مرکزی، انس جهانی و نرخ دلار
  - سنجش وضعیت حباب سکه‌های تمام امامی، بهار آزادی، نیم، ربع و یک گرمی با نشانگر رنگی ریسک
- **تبدیل هوشمند عیار و وزن:**
  - تبدیل وزن بین عیارهای ۱۸، ۲۱ و ۲۴ عیار به صورت بلادرنگ

## 🛠 معماری و توسعه
- **Target SDK:** 34
- **Min SDK:** 24
- **Java Version:** 17
- **UI Framework:** Jetpack Compose + Material 3
- **Reactive State:** Kotlin StateFlow & ViewModel
- **CI/CD:** GitHub Actions با چرخه خودکار کامپایل و انتشار Release APK
