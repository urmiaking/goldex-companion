# GoldEx Companion (همراه گلدکس) 🪙

دستیار جامع، هوشمند و مینیمال ویژه طلافروشان، معامله‌گران و سرمایه‌گذاران بازار طلا، سکه و ارز بر پایه Jetpack Compose با طراحی شیک لایت و دارک و پشتیبانی کامل فارسی (RTL).

## 🚀 قابلیت‌های کلیدی نسخه جدید (v0.4.0)
- **پوسته لایت و دارک داینامیک (Light & Dark Themes):**
  - طراحی تم پیش‌فرض لایت (سفید / چینی) با جزئیات طلایی گرم (`#B8860B`) و کنتراست بالای متون
  - دکمه تغییر آنی تم (خورشید/ماه) در نوار بالایی جهت سوییچ بین حالت روز و شب
- **نوار ناوبری پایینی موبایل (Bottom Navigation Bar):**
  - نوار ناوبری استاندارد Material 3 با ۴ بخش تخصصی همراه با آیکون‌های وکتور اختصاصی:
    1. **طلا و جواهرات (Jewelry)**
    2. **مظنه آبشده و مثقال (Melt)**
    3. **حباب‌سنج انواع سکه (Coins)**
    4. **تبدیل عیار و وزن (Convert)**
- **موتور مظنه زنده و قیمت‌های واقعی (Real Live Rates):**
  - اصلاح کامل وب‌سرویس **طلا.آی‌آر (tala.ir)** و رفع خطای قیمت سکه
  - استخراج هوشمند نرخ دلار آزاد بر مبنای برابری درهم و دلار در وب‌سرویس‌ها
  - اتصال به وب‌سرویس سوم: **شبکه اطلاع‌رسانی طلا و ارز (tgju.org)**
  - کلید سه‌حالته تعویض منبع لحظه‌ای بین `آی‌سیگنال` / `طلا.آی‌آر` / `TGJU`
- **فارسی‌سازی کامل و یکپارچه ارقام:**
  - تبدیل خودکار تمام ارقام تایپ‌شده در ورودی‌های وزن، درصد سود، اجرت و مالیات به اعداد فارسی بدون پرش مکان‌نما
  - تبدیل تمام برچسب‌ها و دکمه‌های سریع (`+۱ گرم`، `+۵ گرم`، `+۱۰ گرم` و `عیار ۱۸، ۲۱، ۲۴`) به ارقام فارسی
- **امضای معتبر و آپدیت بدون نیاز به حذف (Seamless Update):**
  - کلید امضای پایدار درون ریپازیتوری برای آپدیت مستقیم بدون خطای `INSTALL_FAILED_UPDATE_INCOMPATIBLE`.

## 🛠 مشخصات فنی
- **Target SDK:** 34 | **Min SDK:** 24 | **Java Version:** 17
- **UI Framework:** Jetpack Compose (Material 3 Adaptive Themes)
- **Architecture:** MVVM + StateFlow + Kotlin Coroutines
- **Signer:** Persistent 2048-bit RSA Keystore
- **CI/CD:** GitHub Actions Automation Loop
