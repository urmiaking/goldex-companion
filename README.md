# GoldEx Companion (همراه گلدکس)

اپلیکیشن حرفه‌ای محاسبه‌گر مظنه، وزن و عیار طلا و جواهر بر پایه Jetpack Compose و طراحی مدرن متریال ۳ به زبان فارسی (RTL).

## قابلیت‌های کلیدی
- **محاسبه‌گر پیشرفته عیار:** پشتیبانی از عیارهای استاندارد ۱۸ عیار (۷۵۰)، ۲۱ عیار (۸۷۵) و ۲۴ عیار (۹۹۹ - خالص)
- **پشتیبانی از مبنای مظنه:** امکان تنظیم مبنا بر اساس هر گرم طلای ۱۸ عیار یا ۲۴ عیار خام
- **محاسبه سود و کارمزد:** قابلیت تعیین درصد اجرت، سود و مالیات با پیش‌فرض‌های سریع
- **رابط کاربری مدرن:** تم اختصاصی لوکس تیره با المان‌های طلایی و چیدمان کاملاً راست‌به‌چپ (RTL)
- **فرمت‌بندی فارسی:** نمایش اعداد و قیمت‌ها به صورت استاندارد فارسی با جداکننده هزارگان

## معماری و فناوری‌ها
- **Target SDK:** 34
- **Min SDK:** 24
- **Java Version:** 17
- **UI Framework:** Jetpack Compose + Material 3
- **CI/CD:** GitHub Actions با قابلیت تولید خودکار نسخه انتشار (Release APK) و اطلاع‌رسانی خطا در Issue
