نسخه جدید قیراط با بهبودهای زیر آماده استفاده است:

- بازگرداندن ظاهر انتخاب بازه نمودارهای پیشخوان و تحلیل، نوع طرف حساب و منوی موقعیت انبار
- بازگرداندن لینک دفتر فاکتورها و حذف متن اضافی همگام‌سازی از پیشخوان
- باز شدن جزئیات همان نرخ با انتخاب هر آیتم نوار پایین برنامه
- هم‌ترازی کارت دریافت نرخ‌ها با ستون مشخصات گالری در تنظیمات
