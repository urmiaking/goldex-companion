نسخه جدید قیراط برای ویندوز آماده است:

- بازطراحی تخصصی صفحه ماشین‌حساب طلا با کارت نتایج اختصاصی، تفکیک اجزای فاکتور و نگارش حروفی مبالغ
- تفکیک شفاف نرخ مبنا، وزن خالص، اجرت، سود و مالیات بر ارزش افزوده قانونی
- امکان انتقال مستقیم نتایج محاسبه به بخش صدور فاکتور رسمی زرگری
- هماهنگی تابلوی مظنه و پیشخوان با طراحی جدید، نمایش هم‌تراز کارت‌ها و دسترسی سریع به عملیات
