نسخه جدید قیراط با این بهبودها آماده استفاده است:

- پنجره ثبت محصول عریض‌تر و کوتاه‌تر شده و فیلدها با چیدمان منظم کنار هم قرار گرفته‌اند.
- دسته‌بندی و محل نگهداری از منو انتخاب می‌شوند و می‌توانید گزینه جدید را همان‌جا اضافه کنید.
- کد محصولات جدید به‌صورت خودکار و عددی ساخته می‌شود.
- عیار سفارشی مستقیماً داخل گزینه قابل تایپ است و بستن فرم دیگر تأیید اضافی ندارد.
