نسخه جدید قیراط با تغییرات زیر آماده استفاده است:

- باز شدن صفحه اختصاصی هر نماد از کارت‌ها و جزئیات تابلوی نرخ‌ها
- نمایش نمودار روزانه، هفتگی، ماهانه و سالانه با مشاهده نرخ هر نقطه
- نمایش میانگین، کف و اوج نرخ‌ها، تغییر سالانه و حباب محاسبه‌شده طلا و سکه
- نگهداری تاریخچه دریافت‌شده برای استفاده در زمان قطع اینترنت
- حفظ جای قبلی جدول و ورودی‌های ماشین‌حساب هنگام جابه‌جایی بین صفحات
