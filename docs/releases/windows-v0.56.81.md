# نسخه ویندوز ۰.۵۶.۸۱

- کیفیت PDF فاکتور اصلاح شد؛ نوشته‌ها و جدول در بزرگ‌نمایی و چاپ واضح و خوانا می‌مانند.
- کارت‌های فاکتور جمع‌وجورتر شدند و چهار دکمه جزئیات، حذف، تسویه و چاپ در یک ردیف قرار گرفتند.
- دکمه مشاهده با فلش مناسب فارسی به بالای کارت منتقل شد.
- جای دکمه تسویه در فاکتورهای تسویه‌شده حفظ می‌شود تا اندازه کارت‌ها هماهنگ بماند.
