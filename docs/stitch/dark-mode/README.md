# Stitch dark-mode palette

Source: GoldEx Companion App, project `9122211023780147846`, screen `5fd0d3d2ec7241dd81f9533bd0b36391`.
The downloaded HTML and screenshot are visual references, not runtime data.

The theme maps the charcoal canvas (#0B0D11), card surface (#161B22), elevated surface (#1E2530), champagne gold (#D4AF37), bright gold (#F3C64F), and primary text (#F8FAFC) from this reference. Secondary and muted app text use the reference's Tailwind stone-300 (#D6D3D1) and stone-400 (#A8A29E), respectively; Material surface-variant text uses #94A3B8. Decorative card borders use white at 5% opacity, while Material control outlines use #64748B.

Material container and inverse roles are explicitly mapped to prevent default purple surfaces. Gold, emerald, and ruby control fills use dark foregrounds for readable normal-size labels; the reference's white foreground on emerald/ruby fills has insufficient text contrast. The dashboard vault gradient and market gain labels select dark tokens while retaining their existing light-mode rendering. Light palette, typography, layout, financial calculations, navigation, and persistence are unchanged.
